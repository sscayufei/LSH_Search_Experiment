## 设计说明

本阶段只整理和验证既有实验，没有新增检索算法、改变参数、编码数据或重跑 benchmark。
源文件说明了 Exact 字典与完整字符串验证、随机超平面签名、多表桶、候选去重排序和余弦精筛；
给出查询复杂度 `O(Lkd + B + c log c + cd)`、建库复杂度 `O(NLkd)` 与额外空间口径。

四页分别组织为数据与设计、伪代码和理论选型、三方法实测和验证权衡、规模关系与反思。
用户指导文件优先要求可复现 LaTeX/Markdown，环境已有 XeLaTeX/ctex，因此采用 LaTeX 与 Fandol 字体。
结果表由 CSV 格式化生成，避免手工录入；图表只重绘既有测量，不生成新的实验数值。

报告明确说明空 Ground Truth 的条件 Recall、候选与最终结果区别、Exact 捷径遗漏、
边界理论概率未达到 0.9、LSH-only 与混合索引内存差异，以及独立规模运行的计时差异。
百万规模数值分别标记条件理论或外推，没有当作实测。
